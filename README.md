# ⏱️ Stopwatch Web Application

A simple and responsive Stopwatch Web Application built using **HTML, CSS, and JavaScript**. The project uses the **`setTimeout()`** function to implement stopwatch functionality and allows users to start, stop, reset, and record lap times.

## ✨ Features

* Hours, Minutes, Seconds, and Milliseconds display
* Start, Stop, and Reset controls
* Record multiple lap times
* Scrollable lap history
* Clean and responsive user interface
* Built using `setTimeout()`

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
